# ⚡ FSD CodeVault (Lab 01–13) Workspace

Welcome to **FSD CodeVault** — the complete personal online laboratory library for Full Stack Development (Lab 1 to Lab 13).

The modern React application is located in the `fsd-codevault` directory.

### Quick Start:
```bash
# Run local development server
npm run dev

# Or directly in fsd-codevault
cd fsd-codevault
npm run dev
```

### Production Build:
```bash
npm run build
```

See [fsd-codevault/README.md](./fsd-codevault/README.md) for full documentation, deployment steps, and laboratory curriculum details.
